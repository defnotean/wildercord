## 2. Server operations (the nightly crash)

- **The watchdog kills the server every night, 04:03–04:56** (crash reports for Oct 11–22). `backup_world.ps1` runs
  `Compress-Archive` on the ~16 GB world and starves the server thread past `max-tick-time=60000`. On Oct 22 the zip
  finished at 04:48:11 and the crash came at 04:48:16.
- The backup also skips `save-all flush` before copying, so it can miss up to one autosave interval of changes.
- Fix options:
  - Run `save-all flush` first.
  - Replace the zip with an incremental `robocopy /MIR` snapshot, or 7-Zip at low priority with `-mmt=2`.
  - Or set `max-tick-time=-1`.
  - Doing the first two together is the clean fix.
- **The deploy path isn't in git and is inconsistent.**
  - `apply_update.ps1` installs any staged jar with no hash check.
  - `deploy-0130.ps1` falsely reported a failed health check and left the watchdog disabled.
  - Fix: put the deploy and ops scripts under `tools/vps/`, add a SHA-256 check to the auto-install, and write one
    `tools/release.py` that bumps the version, builds on the VPS, runs smoke, tags, uploads and stages.
- **Staging clutter on the VPS:** `deploy-0120/0130.ps1`, `dp.ps1`, `rcon-0100.ps1`, old status and log files, and the
  `pre-0130` backup (once 0.14 is live). `Chunky-Fabric-1.5.3.jar` is unused, since pre-generation is abandoned.
- A player connected with an older client (`syncable attachments wildercord:lesson_pack_view` warning). Consider a
  version check at login with a clear "update your mod" message.
- **Fixed (polish round 1):** the watchdog's reachability ping closed the socket right after reading the status
  packet id, so the server logged an `EncoderException` stack trace every two minutes, burying real errors.
  `Test-Minecraft` now reads the whole response and completes the ping/pong exchange. Regression test in
  `tools/vps/test_ops.ps1` (fake status server that records the ping): it fails on the old watchdog and passes on the
  new one, and the live check passes against port 25565. Not yet installed on the live server.

**Batch B status (2026-10-24):** the backup rewrite, the hash-checked auto-install, a generic `deploy.ps1` and their
tests are in [`tools/vps`](../../tools/vps/README.md), and they're installed on the live server. Still open: proof
from a night without a 04:xx crash, `tools/release.py`, the staging clutter and the old zips (they need the owner's OK
to delete), and the login version check.
