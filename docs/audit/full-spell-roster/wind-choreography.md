# Wind preparations and projectile bodies

Twenty-five runtime wind effects use individually authored airflow recipes. A dedicated renderer
uses quadratic stream bands with a crest traveling through each current, an original striated
filament texture, world lighting and transparency. It does not dispatch through LightParticle.
Wind recipes contain no LightOption rays/arcs/rings. Technical curve emitters are shared; the
current placement, direction, evolution and supporting materials are explicit per effect.
Preparation gathers the flow; flight follows actual position/velocity with a compact body.

## Delivery and integration

Fully wind-authored projectile groups suppress duplicate luminous preparations for Bolt, Arc,
Orb, Spark, Comet, Ricochet, Cluster and Wisp. Field/other delivery markers remain. The casting
glyph stays behind the caster; Self preparations stay attached to the caster. Supporting fusion
materials replace duplicate generic layers for wind-only groups. Mixed groups retain uncovered
layers. Shared flight coverage removes the generic comet and duplicate server travel particles
only when every identity is covered. Unsupported/omitted/foreign members preserve fallback.

Quality is supplied by the owner/other route in the curve option, rather than guessed from camera
distance. Minimal uses fewer bounded curve segments while retaining primary/material identity.
Reduced flash lowers alpha. Camera-aligned vertical tangents use a finite projected fallback axis.
The new registered particle requires matching client/server builds.

## Evidence scope

Native suites exercise the full preparation roster through encoded packets in Full/Minimal,
rear-circle/front-curve placement, evolving/distinct/bounded recipes and supporting materials.
Paid examples use Bolt/Windcut and Self/Swift. Flight tests use fifty paid Survival Bolt casts,
exact synchronized identities, movement, production curve particles, particle-clear recovery,
removed-ID cleanup and supporting materials. Variant examples cover Arc/Cyclone, Arc/Feather Fall,
Pierce/Windcut, Frugal/Swift, covered Windcut/Shock and unsupported Windcut/Umbra.
Close view captures use the actual paid projectile's production particles with a diagnostic camera;
they isolate flight, not the complete unedited cast. Ordinary early/later flight frames retain context.

Existing gameplay, sound dispatch and impacts remain. Full buildup/release/impact/aftermath for all
spells, every delivery/modifier/rank/fusion, reflected/homing/linked visual identity, dark-location
readability, natural combat, shaders, remote multiplayer and measured performance remain open.
No new ability/creature/item/fusion/lore target count is added; the full goal remains active.
