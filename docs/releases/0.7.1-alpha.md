# Wildercord 0.7.1-alpha

**Minecraft Java 26.3 · Fabric · Java 25**

This branding patch includes all gameplay content and fixes from [0.7.0-alpha](https://github.com/defnotean/wildercord/releases/tag/v0.7.0-alpha), with a completely new project icon: a braided Cord, five glowing elemental rune beads, ornate gold fittings and a mint-and-gold magic circle.

- Updated icon inside the mod JAR, on the player guide and on CurseForge.
- Rewritten CurseForge description and summary with current counts, gameplay images, installation help and direct guide links.
- Refreshed CurseForge gallery with real captures of the new casting circles, Cord editor, physical water magic and Cinnamon.
- Includes 350 named runes, 77 named fusion recipes, exact multi-effect weaves, twelve circle disciplines, 297 authored casting sequences, expeditions, defensive equipment, practice, research and Cinnamon.

Install the ordinary JAR on the server and each client with Fabric API 0.161.0+26.3 or newer and Fabric Loader 0.19.5 or newer. The sources JAR is for development. Optional Performance, Balanced and Cinematic launcher profiles contain the same mod; Cinematic adds Iris and requires you to install and select a shader pack separately.

Back up existing worlds before updating this alpha. New dungeons need newly generated chunks; restart to register the practice dimension. Configure Cinnamon's owner in `config/wildercord-cinnamon.json`.
