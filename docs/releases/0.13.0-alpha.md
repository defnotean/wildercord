# Wildercord 0.13.0-alpha — Living world

**Minecraft Java 26.3 · Fabric · Java 25**

Install `wildercord-0.13.0-alpha+mc26.3.jar` on the server and every client, with Fabric API
0.161.0+26.3 and Fabric Loader 0.19.5 or newer. This update adds blocks, items, entities and
packets, so **0.12.x clients must update before joining**. Keep only one Wildercord JAR in
`mods`. The sources JAR is for development.

**Back up your worlds first.**

## New places to find

Each region has its own biome, a building, a resident, a lore route in your journal and a boss.

- **Luminous Reedlands**: pale banks and Moonreed pools, the Tideward Reedkeeper Landing, the
  Drowned Road and the Reed-Crowned Ferryman at the Last Crossing.
- **Windscar Highlands**: the Cairn Lodge and Cairn Keeper, the Paired Cairns and the Glass
  Cartographer, joined to the Scout's Last Cairn.
- **Belowkeeper Hollows**: a Listening Station, its Listener, the Empty Bell route and the
  Hollow Bell.
- **Emberwood Reach**: a Charcoal Yard, its Kiln Keeper, the Eleven Winters route and the Kiln
  Widow.

## Also in this release

Wider bounties and escort jobs, inn raids and rooms, hamlets and wandering caravans, ritual
spells, flawed runes, a spell-duel arena, flying, water and burrowing mounts, guilds, covens and
co-op tribulations, ascension past the Twentieth Circle, a codex bestiary and a stats page. The
full list, with every fix, is in the [changelog](../../CHANGELOG.md).

## Testing and known limits

This build passed the 115 tooling tests and the 14-class native smoke suite on the Windows test
machine. The old 349-class native gate was retired, so a smoke pass is not proof that every
feature works. This is an alpha: report problems on the issue tracker.
