# Wildercord 0.11.2-alpha — Worldgen crash fix

**Minecraft Java 26.3 · Fabric · Java 25**

Install `wildercord-0.11.2-alpha+mc26.3.jar` on the server and every client, with Fabric API
0.161.0+26.3 and Fabric Loader 0.19.5 or newer. Server and players should run the same build.
No world changes: 0.11 worlds load as they are. Keep only one Wildercord JAR in `mods`; the
sources JAR is for development.

## Fixes

- Generating new chunks no longer crashes the server when a farm site, such as the walled
  orchard, places its sign. The sign's text is now written safely while the chunk is still
  being generated. 0.11.1 servers that explore new land should update.

Everything from 0.11.1 (a stronger Cinnamon and the screen fixes) is included.
