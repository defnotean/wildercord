# Wildercord 0.17.0-alpha — Trials of the Sovereign

**Minecraft Java 26.3 · Fabric · Java 25**

Install `wildercord-0.17.0-alpha+mc26.3.jar` on the server and every client, with Fabric API
0.161.0+26.3 and Fabric Loader 0.19.5 or newer. This update adds custom biomes, structures, bosses,
relig-grade weapons, armor, data components, and entities, so **0.16.x clients must update before
joining the server**. Keep only one Wildercord JAR in `mods`. The `-sources` JAR is for
development.

**Back up your worlds first.**

## Highlights

- **Two Living Custom Biomes & Sanctum Wayfinder**:
  - **Astral Ley-Glade (`wildercord:astral_ley_glade`)**: luminous indigo-teal highland forest pierced
    by oxidized copper ley spires, **Leybloom Clusters**, and **Leyweaver Moths**.
  - **Cinder Caldera (`wildercord:cinder_caldera`)**: volcanic ash-and-basalt basin studded with
    **Caldera Slag Vents** and **Caldera Cinderhounds**.
  - **Sanctum Wayfinder**: sneak-right-click to cycle targets across all three Co-Op Trial Sanctums
    and ping directional coordinates and bearing particles.
- **Three Monumental Co-Op Trial Sanctums & Bosses**:
  - **Trial I — Leyline Sanctum & Vaelkhor, the Leyline Sovereign**: `41×32×41` warded Sanctum with
    party HP scaling, Halberd Cleave arcs, **Leyline Conduit** dampening staggers, Phase 2 split-soak
    rings, and `/wildercord sanctum place <leyline|crucible|eclipse>`.
  - **Trial II — Ashen Crucible & Kharvok, the Crucible Sovereign**: `41×32×41` foundry arena featuring
    40-bone Blockbench armor/anvil rig, Anvil Shatter cones, cooperative **Crucible Vent** quenching,
    Crucible Meltdown cooling rings, **Crucible Maul**, **Forgeheart Censer**, and **Crucible Seal**.
  - **Trial III — Astral Eclipse Vault & Nyxara, the Eclipse Sovereign**: `41×32×41` celestial vault
    featuring 40-bone Blockbench crescent-blade rig, Crescent Sever arcs, cooperative **Astral Prism**
    alignment, Phase 2 Total Eclipse rings, **Eclipse Twinblade**, **Astrolabe Dial**, and **Eclipse
    Seal**.
- **Tri-Seal Progression, Sovereign's Mantle & Empowered Apex Mode**:
  - **Instanced Trial Treasuries**: every contributor claims their own once-per-clear relic, Seal,
    and Rune reward.
  - **Sovereign's Mantle**: epic chestplate crafted/forged from the Leyline, Crucible, and Eclipse
    Seals. Wearing the Mantle (or presenting a Seal at a Trial Gate) unlocks **Empowered Apex Mode**
    (enhanced boss health/cooldowns/damage and **Sovereign Crown** rewards) across `9` new
    advancements (`188` visible advancements total).
- **BedrockGeoRig High-Voxel Visual Overhaul (Archivist, Thalassor, Cinder Warden)**:
  - Upgraded **The Archivist** (`28` bones, dynamic eye/rune glow), **Thalassor, Abyssal Sovereign**
    (`25` bones with vaulted wing-fins & branching coral antlers), and **The Cinder Warden** (`25` bones
    with reactive heat magma & furnace eyes) onto smooth ZYX-blended `BedrockGeoRig` models.
- **Two-Way Outdated-Client Version Handshake & Multi-Owner Cinnamon**:
  - Added bidirectional `VersionCheck`/`VersionWatch` warnings for mismatched clients and extended
    `CinnamonConfig` to accept `"owners": [...]` arrays.

The full list, with every change, is in the [changelog](../../CHANGELOG.md).

## Testing and known limits

This build is verified on the Windows test machine (`WIN-I2GBVRRD872`) with the full JUnit unit
test suite, Python packaging/asset/guide/release tests, and native Minecraft 26.3 Fabric client
gametest suites covering Co-Op Trials (Vaelkhor, Kharvok, Nyxara Apex), Trial Biomes & Sanctum
Placement, the 3-boss Visual Overhaul showcases, Deep Ocean, Regions & Worldgen, Combat & Bosses,
and `release-smoke`. Native suites cover the main journeys with deterministic fixtures, not every
survival edge case. This is an alpha: report problems on the issue tracker.
