# Wildercord 0.14.0-alpha — One road

**Minecraft Java 26.3 · Fabric · Java 25**

Install `wildercord-0.14.0-alpha+mc26.3.jar` on the server and every client, with Fabric API
0.161.0+26.3 and Fabric Loader 0.19.5 or newer. This update adds items and packets, so **0.13.x
clients must update before joining**. Keep only one Wildercord JAR in `mods`. The sources JAR is
for development.

**Back up your worlds first.**

## Highlights

- **Four Lamps, One Road**: light the Reedlands, Highland, Belowkeeper and Emberwood lamps and
  answer each regional keeper to finish a journal capstone that ends with the Lamplighter's
  Lantern.
- **New companions**: tame a coffer mimic with books (it follows you and opens as a 27-slot chest
  only you can use) or a thistle hedgehog with sweet berries (it brings you forage finds).
- **Bosses hit harder and move better**: blows land 35% harder and part of them goes through
  armour, with clearer wind-ups, follow-through and staged deaths.
- **Grander buildings**: the world's dungeons and sites were rebuilt bigger and richer, from the
  Ember Sanctum's buttressed hall and crowned dome to the root temple's stepped pyramid. Forest
  sites clear the trees over themselves. The new versions appear in newly generated chunks.
- **Quality of life**: stow Weaver's Silk with `G` or `/silk`, rename homes, and gathering bounties
  and caravans now deal in regional goods.

The full list, with every fix, is in the [changelog](../../CHANGELOG.md).

## Testing and known limits

This build was tested on the Windows test machine: the unit and tooling tests, the native release
smoke suite, ten per-area native suites (combat, rituals, regions, items, GUIs, mounts, towns and a
feature tour) and a screenshot pass over all 76 structures. Those suites cover the main journeys,
not every feature. This is an alpha: report problems on the issue tracker.
