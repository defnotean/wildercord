# Wildercord 0.7.0-alpha

**Minecraft Java 26.3 · Fabric · Java 25**

Install the ordinary `wildercord-0.7.0-alpha+mc26.3.jar` on the server and each client, with Fabric API. The sources jar is for development. The three `.mrpack` files are optional launcher profiles containing the same mod, pinned dependencies and different local visual defaults. Cinematic includes Iris; a shader pack must be installed and selected separately.

## Spellcraft and presentation

- 350 named runes: 39 shapes, 258 effects, 36 modifiers and 17 links; 199 craftable and 53 world runes.
- Twelve craftable circle disciplines: Needle, Bloom, Gyre, Anchor, Reservoir, Crucible, Confluence, Pilgrim, Vigil, Mercy, Tempest and Eclipse. Each has a distinct mechanism and explicit gameplay tradeoff. Groups keep their own disciplines; duplicate circles warn rather than stack bonuses.
- Large charge and release circles follow the caster's rear plane through turns. Smaller forward formations assemble the chosen shape; beams, rain, projectiles and Self casts retain their delivery.
- 297 authored three-beat shape/effect animations. Ingredient materials carry their own textures and movement, including mixed and woven effects; original fire, frost, wind, stone, water, vapour and other materials replace decorative stock-particle paths.
- More detailed Cord, backpack, relic, armour and rune artwork.

## Physical magic and fusion

- Strata Rise builds a temporary collision wall; Tidal Lift borrows and returns actual water sources; Wind Steps creates ascending collision platforms.
- Six new signature recipes: Cinder Bulwark, Root Bulwark, Boiling Surge, Thunder Tide, Rime Causeway and Thunder Walk. Named fusion recipes now total 55 elemental and 22 signature combinations.
- Friendly elements transform temporary terrain; hostile fire and wind can melt, evaporate or dispel it. Saved restoration, ownership limits, loaded-chunk checks and finite lifetimes bound terrain use.
- Exact weaves accept two through eight effect leaves, preserve duplicates and canonical ordering, and sum the complete mana cost. Higher leaf counts require higher tiers.
- Owner-bound innate imprinting and Tier IV soul weaves, with payment and identity checks. Shapes, modifiers and links compose through Knots.
- Fusion Altar Fuse button and Cord mouse handling corrected for Minecraft 26.3.

## Combat and equipment

- Emberweave, Rimebound and Stonebound sets add movement, timed guard and persistent defence choices with drawbacks.
- Mirror-thread mantle opens a timed one-hit mitigation window and returns a small bounded fragment without reflection recursion.
- Reprieve defers part of a large hit into real later damage; debt and cooldown survive logout and equipment changes. Grounding reduces a substantial impulse and grants a short escape gust. Both reduce outgoing power.
- Shared casting locks have capped duration and recovery. Spellguard uses the start-of-tick health snapshot and cast identity, preventing same-cast multi-hit bypass while permitting separate follow-up casts.
- Backpack storage and inventory interactions tightened; custom worn equipment textures and ordinary repair/enchantment support.

## Exploration and life between fights

- Clockwork Crypt, Living Greenhouse and Moving Sky Ruin each have three layout variants, interactive mechanisms and a guaranteed handling relic.
- Root Guardian and Storm Conductor add custom boss models, phased encounters and physical counterplay.
- Dedicated practice dimension with stationary/moving targets, stress scenarios, damage readouts, safe return and optional Precision, Variety and Fusion trials.
- Native Research Notebook, permanent once-rewarded experiments and a 24-entry named spell library.
- Runic Hearth reading lantern, bloom planter, ward chime and three-element cooperative/solo ritual.
- Familiar Companion, Scout, Guardian and Gardener jobs; completed events leave finite saved echoes with once-per-player boons.
- Cinnamon: a small rounded custom dog with a darker coat, tan face/paws, immortal rescue behaviour, one configured owner, remembered sitting, petting, sleep and reusable Red Bone play. Her distribution owner defaults to empty; configure `config/wildercord-cinnamon.json` to activate her.

## Performance and documentation

- Bounded 256-plan compiler cache and decorative packet limits; independent own/other visual settings, reduced flash and camera-motion options.
- Server visual metrics, practice benchmark helpers and frame/profiling tooling.
- Performance and Balanced profiles pin Fabric API/Sodium; Cinematic adds Iris. No third-party shader pack is bundled.
- Reworked searchable player guide with 90 pages, current rune/recipe references, installation, practical builds, new systems, troubleshooting and curated real gameplay captures. Plain Markdown GitBook export and navigation share the same source.

## Verification and updating

Fresh release build and 474 unit tests pass locally. Earlier in-world verification includes the complete 59-entrypoint client run, plus the new circle suite and focused physical-magic, soul-weave, animation and enabled-shader checks. The current 60-entrypoint descriptor is exercised by GitHub Actions; its status is visible on the repository. Local verification does not imply a completed remote run.

Back up existing worlds before updating this alpha. New dungeons need newly generated chunks; restart to register the practice dimension. Update client and server together. CurseForge publication follows separately.
