# Wildercord 0.16.1-alpha — Crossplay, Oathbound Techniques & Sacred Pig Quest

**Minecraft Java 26.3 · Fabric · Java 25**

Install `wildercord-0.16.1-alpha+mc26.3.jar` on the server and every client, with Fabric API
0.161.0+26.3 and Fabric Loader 0.19.5 or newer. This update adds items, a data component, and a
worldgen structure, so **0.16.0-alpha clients must update before joining the server**. Keep only
one Wildercord JAR in `mods`. The `-sources` JAR is for development.

**Back up your worlds first.**

## Highlights

- **Java + Bedrock / Console Crossplay Bridge**: optional runtime bridge (`dev.wildercord.bedrock.*`)
  enabling full Geyser and Floodgate server support with zero extra mods required for Java players.
  Covers server-side localization across all `9,465` strings, `1,045` custom sound mappings,
  item tooltips, written books, and `RitualTabletItem` hold-use channeling, vanilla menu backpack and
  interactable chest bridges (`FusionAltarBlock`, `GuildRequestBoardBlock`), particle/VFX expansion
  and waypoint compass HUD, and Cumulus forms for equipment, the **Wildercord Cast Focus** wand,
  spell lessons, Aura/Blade counters, the Rune Notebook, and the Practice Arena.
- **Oathbound Knights 52 Combat Techniques & Poses**: shared combat technique system
  (`OathboundCombat`, `OathboundTechnique`, `OathboundPose`) with faster attack choreography and
  animations across all four Oathbound Champion Knights.
- **Oathhold Schematic Houses & Guard Law Tuning**: bundled rotating `house1.schem` and
  `house2.schem` outer-ward residences, improved guard watch visibility, and one-heart Watch Stockade
  imprisonment tuning.
- **Sacred Pig Boss-Drop Map Quest & Village**: added the boss-drop map quest leading to the
  `wilds_sacred_pig_village` structure, chest loot table, items (`sacred_pig_map`,
  `sacred_pig_left_nipple`), and advancement.
- **Dungeon Ward & Deep Ocean Placement Fixes**: scans neighboring chunks for warded structure
  starts so ward boundaries hold reliably, and allows `sea-1` surface heights when placing
  submerged Deep Ocean structures.

The full list, with every change, is in the [changelog](../../CHANGELOG.md).

## Testing and known limits

This build is verified with the JUnit unit test suite, Python Bedrock resource-pack and CurseForge
upload script tests, and native Minecraft 26.3 Fabric client verification covering all mixin targets
(`MixinTargetsTest`) and payload codecs (`PayloadCodecRoundTripTest`) without Geyser or Floodgate
loaded. Full manual playthrough of every crossplay interaction and survival progression path is not
claimed. This is an alpha: report problems on the issue tracker.
