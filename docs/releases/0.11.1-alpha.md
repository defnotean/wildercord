# Wildercord 0.11.1-alpha — A stronger Cinnamon and screen fixes

**Minecraft Java 26.3 · Fabric · Java 25**

Install `wildercord-0.11.1-alpha+mc26.3.jar` on the server and every client, with Fabric API
0.161.0+26.3 and Fabric Loader 0.19.5 or newer. Server and players should run the same build.
No world changes: 0.11.0 worlds load as they are. Keep only one Wildercord JAR in `mods`; the
sources JAR is for development.

## Cinnamon

While treats keep Cinnamon big, she grows stronger: a harder bite, double health, armour and a
bigger fatigue budget. She joins her owner's fights and casts fire, frost, lightning and arcane
bolts at their enemies, plus a healing beam when her owner drops below half health. Her spells
follow her owner's friendly-fire rules and never join a Master's trial. At normal size she is
unchanged.

## Fixes

- Tooltips in the Cord screen show again: the mana, heart, defence and help badges, spell
  sockets and Codex runes. A spell description beside the tool buttons left its clipping region
  open, which hid every tooltip drawn after it.
- Opening a Master study you can't read yet (circle too low, or the boss victory missing) now
  stays open and says what it needs, instead of closing at once.
- The Aura screen's Master form link moved into the header beside the title, so it no longer runs
  across the breathing-method portrait. On the Writing, Blade and Lineage tabs, the method, stage
  and aura line fits between the link and Master's Arts instead of printing over them.
